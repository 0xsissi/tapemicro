# RainbowKit 钱包与挂售份额保护

网站主应用使用实际 RainbowKit 2.2.11、Wagmi 2.19.5 和 Viem 2.57.7；交易继续通过已连接钱包的 EIP-1193 provider 交给 Ethers 签名。界面、样式和许可证随静态站点打包，不依赖 CDN。钱包组件单独加载，公开盘口读取不等候组件下载。

支持已安装钱包的 EIP-6963 发现，以及旧版 window.ethereum / providers 注入。具体可连接的钱包以浏览器实际发现为准；不保证所有钱包版本都经过实机测试。现已配置 WalletConnect 手机扫码；接入与验证范围见 [扫码连接说明](walletconnect.zh-CN.md)。手机也可在钱包 App 内置浏览器打开本站。

仅恢复上次选中的已授权钱包，不因刷新再次请求授权；主动断开后刷新保持断开。账户或网络变更清空旧签名器，非 BSC 网络停止签名并提供切链弹窗。不会保存私钥。钱包弹窗使用与主站一致的字号、配色及中英文；固定滚动条空间避免打开弹窗时移动正文。

顶部与收益页使用同一待领 BEM 合计，包含零份额资产的已结算历史收益。数字显示精度不同，底层整数合计一致。

卖单每行只显示该单的可买 H，移除容易被理解为单台算力的盘口累计量。

“立即卖出”最多使用每个 ID 的 `max(balance − reserved, 0)`，包括“全部”快捷按钮和单张买单匹配。多笔成交合并检查同一 ID 的总用量。核验及签名前按最新区块重新读取余额与挂售预留，发现变化要求重新匹配或先撤单。全部持仓已挂售时，盘口提示“请先撤销卖单”。

这属于本站交易操作保护，**不是链上锁仓**。线上市场合约及金库没有修改；用户仍能通过钱包直接转走份额，或者直接调用市场合约消耗已挂售份额，导致旧卖单失效。合约按实际余额执行，不能重复卖出同一份额。若要求所有外部调用也受硬锁限制，需要另行设计、测试及部署合约，不能仅改网页实现。

验证包括 143 项前端、工具和本地实际合约测试；新增本地链案例在报价后挂售全部份额，核验和交易准备均拒绝，撤单后恢复。RainbowKit 浏览器虚拟钱包记录验证连接、刷新恢复、换账户、切链、主动断开、第二钱包签名桥及手机英文弹窗；未连接真实钱包或发送主网交易。后续补测时浏览器控制被 Work 设置禁用，未补做无插件/旧版注入的浏览器场景，也未重拍最后的提示文案。

# 钱包恢复、收益汇总与连接状态

2026-10-18

顶栏和领取页统一汇总每台资产的 `pending`（包含可收割的上游收益），包括已经卖出份额后仍留在原账户名下的历史收益。之前顶栏误用了仅已入金库的 `funded`，因此两个位置的金额不同。汇总使用 BigInt；顶栏按原设计显示 4 位小数，领取页显示 6 位，顶栏悬停可查看完整精度。

浏览器只保存上次选择的钱包的公开标识，不保存私钥、签名者或授权。刷新、从指南返回、账户变化和短暂断线时，通过 `eth_accounts`、`eth_chainId` 核验现有授权后静默恢复。不会自动调用 `eth_requestAccounts` 或切换网络；用户主动断开后，刷新仍保持断开。钱包锁定、撤销站点权限或切到其他链时，仍需用户在钱包里解锁、授权或切回 BSC。

RPC 恢复和钱包授权分开处理；读取节点故障不会使用户反复授权。异步恢复带有账户、网络及操作代次核验，旧请求不能覆盖新的选择。保留现有 EIP-1193 / EIP-6963 注入式钱包；本次未接入需要公开 Project ID 的扫码连接服务。

正式站点不再把普通连接过程插入正文上方。首次读取及重连使用既有固定位置的状态提示；手机端提前保留余额两行高度，避免加载数据后页面换行下移。

验证：新增 8 项测试，完整前端/工具/本地链测试共 139 项通过。隔离的虚拟钱包浏览器检查覆盖桌面、手机英文、静默恢复、账户变化、暂时断线、错误网络、主动断开和指南往返；未连接真实钱包、未发送主网交易。合约及已部署地址均未修改。

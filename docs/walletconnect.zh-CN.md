# WalletConnect 手机扫码连接

主应用在 RainbowKit 内提供 WalletConnect 扫码入口，保留已安装钱包的 EIP-6963 / EIP-1193 连接。使用公开 Project ID `0c8f8955535c492a5f7a990b773b72fb`，应用名称 TapeMicro，应用 URL `https://tapemicro.top`，图标随静态站点发布。该 ID 没有后台管理权限。

仅配置 BSC（56），不读取浏览器里的 RPC、链或 Project ID 覆盖值。本地 Anvil 与离线演示不初始化扫码连接。页面 CSP 允许官方中继的 WSS 连接，演示保持 `connect-src 'none'`。

使用 RainbowKit 自己的二维码界面，排除 SDK 同时生成的另一套 AppKit 弹窗连接器，防止出现两套连接流程。Wagmi 提示的日志库依赖采用固定 `pino@10.0.0` 覆盖；依赖及许可证随源码固定。

恢复连接只初始化上次选择的钱包；恢复插件钱包时，不等待 WalletConnect 的远程初始化。首次访问不主动发起配对，也不替用户确认连接。手机扫码后的授权、切换账户和签名均由用户在手机钱包确认。主动断开会记录偏好，即使远端清理失败也不会因刷新主动重连。

网站设置已经随代码发布。Reown 后台的域名白名单须包含 `https://tapemicro.top`；将来换用其他 DeWEB 域名也需要加入相应域名。公开 Project ID 不能用来修改后台设置。本次浏览器控制被 Work 设置禁用，未代登录后台，也没有完成真实手机钱包扫码授权或签名验收。

发布前执行 149 项前端、工具和本地链测试、60 项合约回归及 3,200 步账本对账。中继探测使用真实 TLS 及 `Origin: https://tapemicro.top`，只申请临时配对 URI，随后断开并删除临时配对；不保存 URI、会话密钥，不使用真实钱包，也不发送主网交易。具体中继结果见公开发布验收记录。

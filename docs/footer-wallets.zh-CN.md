# 页脚与钱包连接修正

2026-10-17，前端更新，合约、BSC 地址、市场版本及手续费规则不变。

页脚移至 main 之外，页面以至少一屏高的纵向弹性布局承载。短页面将页脚推到视口底部，长页面在正文之后自然显示，不使用 fixed 覆盖内容。未连接时移除收益/积分容器为持仓加载预留的 540px 最小高度；桌面短页实测页脚底部与视口高度均为 720px，手机长页页脚跟随内容且没有横向溢出。

BSC 标签变为普通文字，移除连接设置弹窗、错误状态和当前钱包中的配置入口。主站只读取随包发布的网络、RPC 和合约配置，旧 localStorage 自定义连接记录不再读取；历史市场恢复仅可选择内置允许列表，本地链仍限专用构建和 localhost。RPC 故障由既有只读连接池自动切换。

钱包增加 EIP-6963 多插件发现及选择，并保留 EIP-1193/window.ethereum 和旧 providers 数组回退。不使用钱包自报图标或外部资源，名称转义展示、以 provider 实例去重。选择后仅监听该钱包；更换钱包会解绑旧监听，即使旧钱包不提供 removeListener 也不会让过期事件清空新会话。

连接先请求账户，再请求切换至 BSC。钱包返回 4902 时，用内置 BSC 元数据请求添加主网；用户取消不自动重试。不支持网络切换则明确提示在钱包中切换，最终核对实际链 ID 后才连接。正常的同账户/同链通知不重复断连。

兼容范围：提供标准 EVM provider 的桌面插件和钱包 App 内置浏览器。没有 WalletConnect 或扫码中继，普通手机浏览器中未注入钱包时不能直接扫码连接。硬件设备需通过兼容的钱包界面使用，本轮没有逐品牌真机验收。

验证：131 项前端/工具/真实本地链测试通过，其中新增 10 项发现、去重、延迟注入、拒签、添加/切换链、错误网络和旧钱包事件隔离测试。合约源码与字节码未变，保留原 60 项合约测试及 3,200 步随机账本证据，无新增主网交易。本机浏览器用明确标注的虚拟钱包验收第二钱包选择及 ETH→BSC 切换；中文桌面、英文 390px、中文 320px 长短页检查及截图见 output/wallet-layout/。

规范：[EIP-1193](https://eips.ethereum.org/EIPS/eip-1193)、[EIP-6963](https://eips.ethereum.org/EIPS/eip-6963)。

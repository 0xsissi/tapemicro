01 / 认识 TapeMicro

一台原矿机 = N 份 1H 微矿机

原矿机由合约独立托管，按算力 1:1 发行微矿机。每 1H 微矿机和原矿机的每 1H 同权同产，收益按全网实际算力结算。

份额单位1H = 1 份按原矿机已验证算力发行
收益同权同产每 1H 与原矿机相同
拆分 / 赎回0 费用只付链上 Gas
交易费1%只由主动成交方支付

02 / 准备

准备一个 BSC 钱包和少量 BNB

TapeMicro 运行在 BNB Smart Chain 上。所有操作都在你自己的钱包里确认，网站不会获取你的私钥或助记词。

  1. 安装钱包

    电脑可以连接已安装的 EVM 钱包插件，也可以选择 WalletConnect，用手机钱包扫码连接。手机也可在钱包 App 的内置浏览器里打开 tapemicro.top。

  2. 切换到 BSC 主网

    网络选 BNB Smart Chain（Chain ID 56）。网站检测到其他网络时会提示切换。

  3. 准备 BNB

    立即买入要付成交金额 + 1% 服务费；每次链上操作还需要 BNB 支付 Gas，请按钱包的实际预估预留。

  4. 点击右上角「连接钱包」

    连接只读取你的地址和链上数据，不等于授权，不会动你的任何资产。

只认官方域名 tapemicro.top。 群聊、私信里的相似链接、“空投领取”页面都不要连接钱包。
03 / 拆分

把原矿机拆成微矿机

适合手里有 TapeOut / Behemoth 原矿机、想部分卖出或提高流动性的人。拆分不收手续费，拆分后你仍然持有全部份额，收益照常归你。

  1. 选择原矿机

    连接钱包后自动读取你钱包里的原矿机，也可以按「矿机来源 + 编号」查找。不能入池的矿机会标明原因。

  2. 核对可拆分 H

    拆出的份数 = 这台矿机的已验证算力。拆分前已产出的 BEM 会在拆分时先发到你的钱包。

  3. 两次钱包确认

    第 1 步授权这一台 NFT（approve，只针对这个编号）；第 2 步确认拆分。完成后微矿机直接到你的钱包。

哪些矿机可以入池

入池条件由合约在拆分那一刻检查，前端绕不过去：

可以入池
  • TapeOut 或 Behemoth 矿机
  • 状态正常、算力已全部验证
  • 通过官方的电路反例检查
不能入池
  • 最优首创矿机（含额外设计加成）
  • 未验证、部分未验证的矿机
  • 验证失败、已失效或停止挖矿的矿机
只能通过「拆分」按钮存入。 直接用钱包把 NFT 转给金库或托管地址（transferFrom），不会发行微矿机，也没有找回入口。
04 / 买入

买入微矿机：立即买入或挂买单

想马上买到，用「立即买入」；觉得现价贵，用「挂单买入」出个价等人卖给你。

立即买入

  1. 输入想买的 H

    默认从最低卖价开始自动凑单，可以跨多台矿机一起买，单笔最多 16 笔成交。要指定矿机，点击对应卖单右侧的「买入此单」，再填写数量；此时只匹配该卖单，数量不足或失效时不会改买其他矿机。点击「恢复自动匹配」可重新按价格凑单。

  2. 核对报价再确认

    看清成交金额、1% 服务费和合计支付，再在钱包里确认。买入不需要任何授权，钱包里只应出现支付 BNB。

  3. 份额到账，开始拿 BEM

    通常先收割并结清卖家的旧收益，你从成交时开始分配后续收益。若官方收割暂时失败，尚未收割的 BEM 会随份额转给新持有人。

报价期间盘口有变化（被别人先买走、卖家撤单），交易会安全失败，不会多扣钱。重新核对报价即可。

挂单买入（挂买单）

  1. 选接受范围

    默认「任意矿机」：接受当前和以后新入池的可交易矿机。各原矿机收益和风险独立；只想买某几台，可切到「指定矿机」勾选。

  2. 出价和数量

    出价如果已经高于或等于在售最低价，页面会提示你直接「立即买入」，更便宜也更快。

  3. 托管 BNB，等人成交

    挂单时把 数量 × 单价 的 BNB 存进市场合约托管。有人卖给你时立即成交，份额直接进你的钱包。

  • 挂买单不收费，卖给你的一方付 1% 服务费，你按出价付款。
  • 没成交的部分随时撤单，托管的 BNB 全额退回；到期未成交也可一键退款。
  • 停挖或异常矿机的份额，合约不允许卖进你的买单。
05 / 卖出

卖出微矿机：卖给买单或挂卖单

着急变现，用「立即卖出」直接卖给现有买单；想卖个好价，用「挂单卖出」自己定价。

立即卖出

输入想卖的 H，按最高买价开始匹配。只匹配接受你这台矿机的买单。卖款扣除 1% 服务费后直接到账。

挂单卖出

选一台矿机的份额，设置单价 / H、数量和有效期（1 / 7 / 30 天）。挂单不收费，买家付 1%。

收益怎么算

通常成交时先结清旧收益；已经结算的 BEM 仍归卖家。若官方收割暂时失败，尚未收割的 BEM 会随份额转给买家。

  1. 选择份额

    每张卖单只卖一台原矿机的份额。持有多台的，分别挂单。

  2. 设置单价、数量和有效期

    如果你的卖价不高于某张买单的出价，页面会提示你直接卖给这张买单，成交更快。

  3. 首次挂单或卖出时授权一次

    钱包会请求 setApprovalForAll，授权市场合约转移你的微矿机份额（包括金库内所有原矿机对应的 Micro 批次）。它不包括 BNB、BEM 或你的原矿机 NFT。

  4. 挂单后份额仍在你的钱包

    挂单只是给这部分份额加上“预留”，成交时才转给买家。没成交的部分随时撤单。

  5. 卖款到账

    卖款直接打到你的钱包。如果你的地址是不能接收 BNB 的合约钱包，卖款会记入「待提取余额」，可以提取到你指定的地址。

份额转走后记得撤旧卖单。 挂单期间把份额转到别的钱包，旧卖单的预留额度不会自动释放，页面会标为“不可成交”，撤掉后再重新挂。
06 / 领取

领取 BEM：持有多久，就拿多久的收益

每台原矿机的收益单独累积，按份额分配。已结算收益留给原持有人；官方收割失败时，尚未收割的收益随份额转移。

  1. 勾选要领取的矿机

    页面按原矿机列出你的待领 BEM，包括已经全部卖出、但还有历史收益的矿机。

  2. 确认领取

    领取时合约先向官方挖矿合约收取最新产出，再按份额发给你。矿机多时会分几笔依次处理，中断后可以继续。

官方领取暂时失败时： 页面会提示「官方领取暂不可用」。你可以稍后重试，或先用「领取已同步 BEM」领走已经同步进金库的部分。未收割部分可稍后重试；期间若转走份额或赎回，它会随份额或原矿机转移。
BEM 有 8 位小数，小额持有时每天的产出可能只有零点零几个 BEM，属于正常。
07 / 赎回

集齐一台的全部份额，赎回原矿机

微矿机和原矿机等价，绝大多数人不需要赎回。只有想把整台矿机拿回钱包时才用。

  1. 集齐 100% 份额

    比如 100H 的矿机需要同一台的 100 份。不同矿机的份额不能混用。

  2. 在「领取」页点这台矿机的「赎回整台」

    持有量达到 100% 时，这一行会出现「赎回整台」按钮。确认后份额销毁，原矿机 NFT 回到你的钱包，不收手续费。

  3. 历史 BEM 照常领取

    赎回前已经分给你的 BEM 不受影响，赎回后仍然可以领。

份额丢失会导致无法赎回整台。 如果有份额被转进无法取回的地址，这台矿机就永远凑不齐 100%，但其余份额仍然正常挖矿、领取和交易。赎回后原来的卖单无法成交，记得撤单。

邀请规则

  • 在「积分」页复制你的邀请链接，形如 tapemicro.top/?ref=0x…。
  • 新用户通过你的链接首次成功参与时，交易须携带邀请标识才能绑定。仅打开链接或连接钱包不绑定；之前已有未带标识的协议交互，可能不再符合新用户条件。绑定后不再改变。
  • 被邀请人每笔成交积分 +10%；你额外获得被邀请人成交基础积分的 10%。
  • 只有一级邀请；自己邀请自己不计。
邀请奖励由链上成交记录统计，可能比成交积分晚一些显示。

11 / 常见问题

常见问题

收益
微矿机的收益和原矿机一样吗？
一样。每 1H 微矿机对应原矿机的 1H 已验证算力，产出按全网实际算力分配。持有 10H 微矿机，就拿这台原矿机 10% 的产出（假设它是 100H）。
买到之后多久开始有收益？
通常从成交时开始，之前的收益先结给卖家。若官方收割暂时失败，未收割的 BEM 随份额转给买家；已经结算的收益仍归卖家。
为什么领到的 BEM 这么少？
日产随全网算力、发行参数及原矿机状态变化，不是固定值。请查看交易页按最新参数估算的「每 100H 日产」；实际到账以链上领取为准。
不领取的话收益会过期吗？
已结算给你的 BEM 会记在链上，卖出或赎回后仍可领。尚未收割的部分，在官方收割失败时会随转出的份额或赎回的原矿机转移。
原矿机停挖或变成异常了怎么办？
它的份额会被标为不可交易，不能挂单、买入或卖进买单。已产生的收益仍然可以领取，集齐全部份额也仍然可以赎回。
交易
不同原矿机的微矿机可以混在一起吗？
不能。每台原矿机的份额是单独的一种资产，收益也单独结算。你的持仓会按原矿机分行显示。买入时系统可以跨矿机凑单，到账后仍然分开记录。
挂单和买单可以撤吗？
随时可以。撤卖单立即释放预留份额；撤买单退回未成交部分的全部托管 BNB。到期未成交的订单也可以一键清理退款。
为什么只成交了一部分？
凑单受已加载深度和每笔最多 16 条成交限制，确认前会显示实际可成交数量。提交后整批原子执行：报价失效会整笔失败，不会跳过失效单只成交一部分。请重新核对报价后提交。
钱包已经确认，页面为什么还没更新？
链上确认需要几秒。可以在右上角「交易记录」查看状态和 BscScan 链接，确认后页面会自动刷新；一直没变化时手动点「刷新」。
卖款为什么没直接到账？
如果收款地址是不能接收 BNB 的合约钱包，卖款会记入「待提取余额」，在交易页提取到任何能接收 BNB 的地址即可。
拆分与赎回
可以直接把 NFT 转给金库吗？
不可以。只能通过「拆分」按钮存入。直接转账不会发行微矿机，也没有找回入口。
为什么我的矿机不能拆分？
只接收普通已验证矿机。最优首创、未验证、验证失败或已失效的矿机不能入池；入池时合约还会做官方反例检查，没通过也会被拒绝。
拆分会损失收益或份额吗？
不会。拆分不收费，100H 拆出 100 份全部归你，拆分前的收益在拆分时先发给你。
联系与支持

遇到问题时，请提供所在页面、钱包地址和交易哈希。任何人索要私钥、助记词或验证码，都不要提供。

风险提示

参与前请了解：原矿机可能停挖或变成异常状态；BEM 价格和全网产出都会变化，历史产出不代表未来；官方挖矿合约的领取可能暂时失败；智能合约存在未知漏洞的风险，目前合约未经第三方审计。请只投入你能承受损失的资金。
